## 👨‍💻 Tentang Saya
 
Saya web developer asal Indonesia yang mengerjakan beberapa proyek klien secara paralel, mulai dari **storefront e-commerce**, **platform organisasi/institusi**, hingga **aplikasi full-stack** dengan alur bisnis yang kompleks. Saya juga memimpin divisi **Custom Program**, membawahi PM dan programmer, dan merancang workflow agar pengerjaan proyek tetap tertib dan terukur.
 
- **Peran:** Full-Stack Web Developer & Ketua Divisi Custom Program
- **Lokasi:** Indonesia
- **Stack harian:** Next.js, Tailwind CSS, Prisma ORM
- **Fokus:** Clean architecture, RBAC & alur dokumen, e-commerce, interactive web
- **Manajemen tim:** Workflow terstruktur dengan Trello
- **Sedang dikerjakan:** Blueprint arsitektur frontend yang reusable untuk proyek-proyek berikutnya
- **Latar belakang:** Fondasi pemrograman dari Java (multi-threading & string manipulation)
